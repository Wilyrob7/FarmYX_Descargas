# FarmYX — Descargas

FarmYX es una aplicación móvil para Android orientada a la gestión de inventario
farmacéutico: escaneo de códigos de barras, control de existencias, movimientos
y alertas de vencimiento.

## Descargar el APK

El archivo de instalación se publica siempre con el mismo nombre: **`FarmYX.apk`**.

Enlace permanente a la versión más reciente:

https://github.com/Wilyrob7/FarmYX_Descargas/releases/latest/download/FarmYX.apk

> Nota: el enlace funcionará a partir de la primera publicación (release) de la
> aplicación. Si todavía no abre, la versión aún no está publicada.

## Instalación

1. Descarga `FarmYX.apk` a tu teléfono Android.
2. Abre el archivo. Android mostrará el aviso de seguridad sobre instalar
   aplicaciones de **orígenes desconocidos**.
3. Otorga el permiso (por ejemplo, «Permitir de esta fuente» para el navegador
   o el gestor de archivos que uses) y vuelve a pulsar **Instalar**.
4. Al finalizar, abre FarmYX.

## Comprobar la integridad del archivo (SHA256)

Antes de instalar, puedes verificar que el APK no fue alterado:

- **Windows (PowerShell):** `Get-FileHash FarmYX.apk -Algorithm SHA256`
- **Linux / macOS:** `sha256sum FarmYX.apk`

Compara el valor obtenido con el hash SHA256 publicado en la descripción de la
[release más reciente](https://github.com/Wilyrob7/FarmYX_Descargas/releases/latest).
Si no coinciden, **no instales** el archivo y vuelve a descargarlo.
